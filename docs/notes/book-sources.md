# Book and audio sources (reference)

Per-scholar and per-book notes: where each book's audio comes from, which copies to avoid, completeness checks, and the category sections. Moved verbatim from CLAUDE.md. Read the entry for a book before changing it, or the host notes before adding a book from the same place.

## Category sections

- A category can group its books into `sections` (`{ title, items }`), shown on the category page as foldable groups that start closed (the programme's manager asked for this): العقيدة has مؤلفات ومحاضرات العلماء المعاصرين (formerly مؤلفات المعاصرين; first since 3 Oct 2026, the brother's order), مؤلفات الإمام محمد بن عبد الوهاب, مؤلفات ابن تيمية and مؤلفات العلماء المتقدمين إلى المتأخرين (formerly مؤلفات السلف, then مؤلفات المتقدمين إلى المتأخرين) (order set by the manager, 1 Oct 2026; these names are the brother's correction, 2 Oct 2026), علوم العربية has النحو, الصرف and البلاغة. الآداب (named آداب الطالب until 1 Oct 2026; its slug is still `adab-at-talib`) had a الدعوة section; the manager removed it (1 Oct 2026) and moved its books: al-Jabiri's الأمر بالمعروف والنهي عن المنكر to مؤلفات ابن تيمية and al-Fawzan's وجوب الأمر بالمعروف (Ibn Baz) to مؤلفات المعاصرين (placed right after al-Najmi's الطائفة الناجية المنصورة by the brother, 2 Oct 2026). Book pages stay at `/<category>/<slug>/`. Code that walks all books uses `itemsOf(c)` from `content.mjs`.

- Ibn Uthaymeen's books (زاد المستقنع, الكافي) play straight from his audio server, sounds.binothaimeen.net, which allows skipping through. Their lesson lists have no `source` (the importer skips them) and were written once from binothaimeen.net's API: `https://shekhapi.binothaimeen.net/course/sections/audio_library/children/<section id>?pageSize=100` lists a book's parts, `.../many_lessons/<part id>/200` a part's lessons, each with `certificate_url` (the mp3's path on sounds.binothaimeen.net) and `objective.size`. When a book's section id is unknown, the mp3s can also be found by their path pattern, `othaimeen_K/<book>_<n>/<book>_<n>_othaimeen_K_<NN>.mp3`, where `<n>` is the recording (الشرح الأول / الثاني); شرح البلاغة (`albalaghah`) was found this way.
